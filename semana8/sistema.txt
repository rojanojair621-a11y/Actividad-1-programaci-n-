el comando uname -a muestra información del sistema operativo, la versión del kernel y la arquitectura del equipo.

El comando whoami muestra el nombre del usuario que está utilizando el sistema. En este caso el usuario es root.

Conocer esta información es útil para administrar servidores porque permite identificar el entorno de trabajo, verificar permisos de usuario y realizar configuraciones o tareas de mantenimiento de forma adecuada.
